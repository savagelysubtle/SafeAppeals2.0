# A Quick Look Around

The tour walks through eight parts of the sample case workspace:

1. **Case files** — your folder list on the left
2. **AGENTS.md** — the case brief at the workspace root
3. **core_references/** — shared statutes and policy materials
4. **Private Search** — on-device search status in the status bar
5. **Case Timeline** — hearings, deadlines, and key dates
6. **Integrated browser** — research pages stay inside the app
7. **Chat** — where you ask the assistant about the matter
8. **Approval prompt** — a static preview of what you see before any file change

This tour does **not** run the AI, spend credits, or install Private Search models. Setup and credits are separate steps you choose later.
