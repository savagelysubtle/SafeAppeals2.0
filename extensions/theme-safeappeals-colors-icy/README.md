# Safe Appeals Icy Dark

Arctic icy theme - Cool and refreshing

## Color Palette

- **Status Bar**: `#A6D8E7`
- **Primary Accent**: `#A6D8E7`
- **Secondary Accent**: `#5B8FA3`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Icy)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Icy Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Icy)"

Or mix and match with any other icon theme!
