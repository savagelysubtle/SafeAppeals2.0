# Safe Appeals High Contrast

High contrast theme - Maximum accessibility

## Color Palette

- **Status Bar**: `#00FF00`
- **Primary Accent**: `#FFFF00`
- **Secondary Accent**: `#00FF00`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Contrast)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals High Contrast"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Contrast)"

Or mix and match with any other icon theme!
