# Safe Appeals Pastel Dark

Soft pastel theme - Calming and minimal

## Color Palette

- **Status Bar**: `#8DCDB7`
- **Primary Accent**: `#B8E6D5`
- **Secondary Accent**: `#8DCDB7`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Pastel)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Pastel Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Pastel)"

Or mix and match with any other icon theme!
