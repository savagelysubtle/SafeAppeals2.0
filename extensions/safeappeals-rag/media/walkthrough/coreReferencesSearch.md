# Core References and Search Without Credits

Create a `core_references/` folder for shared policy manuals, regulations, and
textbooks. Case files index separately. Searching the private index does **not**
spend credits and does not require the AI to run.

[Create Core References Folder](command:safeappeals-rag.scaffoldCoreReferences)

[Search Private Index](command:safeappeals-rag.search)

[Show Private Search Status](command:safeappeals-rag.showStatus)
