# What Stays on This Computer

Private Search builds an index on **this computer** so you can find passages in
your case files and core references without uploading whole files for every
search.

- Index data and search tools stay on this machine.
- Nothing is downloaded until you consent.
- You do not need credits or a live agent to set up or use Private Search.

Cloud chat is separate: only the text you choose to send when you ask the
assistant a question leaves this computer.
