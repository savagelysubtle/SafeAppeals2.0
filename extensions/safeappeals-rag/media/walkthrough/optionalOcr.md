# Optional OCR for Scanned PDFs

Born-digital PDFs can be indexed without OCR. Scanned PDFs need optional
scanned-PDF tools (~7 GB) that run only on this computer.

This step is optional. Nothing downloads unless you choose to install and
consent. You can check hardware readiness first, or skip OCR entirely.

[Show Hardware Snapshot](command:safeappeals-ml.showHardwareSnapshot)

[Install Unlimited OCR (consent required)](command:safeappeals-ml.installUnlimitedOcr)
