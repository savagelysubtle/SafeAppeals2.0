# One Folder = One Case

Each case lives in its own folder. Initializing it creates:

- **`AGENTS.md`** — the case brief: client, opposing party, claim number,
  jurisdiction, and key dates. The agent reads this automatically at the
  start of every conversation, so it always knows which case it is working on.
- **`.safeAppeals/case.json`** — the same information in structured form,
  used by the timeline, file organizer, and email features.
- **Standard case folders** (your choice) — `Medical_Reports`,
  `Correspondence`, `Decisions_and_Orders`, `Evidence`, `Personal_Notes`, and
  `tosort` for unsorted intake. Each folder gets its own small `AGENTS.md`
  telling the agent what belongs there and how to treat it.

`AGENTS.md` is a plain Markdown file — add your own notes, background, and
preferences below the managed block and the agent will follow them.

Update the details anytime with **Safe Appeals Case: Edit Case Info**.
