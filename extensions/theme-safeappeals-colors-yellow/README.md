# Safe Appeals Yellow Dark

Bright yellow theme - Optimistic and cheerful

## Color Palette

- **Status Bar**: `#D4AC0D`
- **Primary Accent**: `#F7DC6F`
- **Secondary Accent**: `#D4AC0D`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Yellow)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Yellow Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Yellow)"

Or mix and match with any other icon theme!
