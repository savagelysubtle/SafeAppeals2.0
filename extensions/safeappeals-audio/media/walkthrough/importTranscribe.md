# Import and Transcribe

Import an existing audio file, or run transcription on a recording you already
have. Speech-to-text uses a local Whisper model — audio does not leave this
computer for transcription.

Whisper models install **only with your consent**. This tutorial does not
download a model for you. When you are ready, choose a model or start
transcription; Safe Appeals will ask before anything is installed.

[Import Audio File](command:safeappeals-audio.importAudio)

[Transcribe Recording](command:safeappeals-audio.transcribe)

[Choose Whisper Model](command:safeappeals-audio.chooseWhisperModel)
