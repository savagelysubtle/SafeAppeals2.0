# Safe Appeals File Icon Theme

The official file icon theme for Safe Appeals Navigator.

## Features

- **Folder Icons**: Distinct icons for collapsed and expanded folders
- **Root Folder Icons**: Special icons for root/project folders
- **File Type Icons**: Support for 60+ file types including:
  - Documents: `.pdf`, `.docx`, `.xlsx`, `.pptx`
  - Code: `.js`, `.ts`, `.py`, `.html`, `.css`, `.json`, `.xml`
  - Media: `.png`, `.jpg`, `.mp4`, `.mp3`
  - Archives: `.zip`, `.rar`, `.7z`
  - And many more!

## Color Palette

The icon theme uses a modern, professional **green** color scheme designed to:
- Match the Safe Appeals Navigator green theme
- Provide clear visual distinction between file types
- Maintain readability in both light and dark themes
- Use professional green tones (#7BC96F for folders, #52A447 for root folders)

## Technical Details

- All icons are SVG format for crisp rendering at any size
- Icons follow VSCode's icon theme specification
- Supports language-based icon selection
- Includes special icons for common configuration files
