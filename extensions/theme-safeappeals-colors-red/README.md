# Safe Appeals Red Dark

Bold red theme - Attention-grabbing and energetic

## Color Palette

- **Status Bar**: `#E85D75`
- **Primary Accent**: `#E85D75`
- **Secondary Accent**: `#C0374A`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Red)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Red Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Red)"

Or mix and match with any other icon theme!
