# Safe Appeals Green Dark

Official green theme - Professional and trustworthy

## Color Palette

- **Status Bar**: `#A6E22E`
- **Primary Accent**: `#A6E22E`
- **Secondary Accent**: `#8CBF22`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Green)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Green Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Green)"

Or mix and match with any other icon theme!
