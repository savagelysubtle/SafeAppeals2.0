# Case Folder Layout

Keep case documents in a flat layout at the workspace root (no `Case_Files/`
wrapper). Standard folders:

| Folder | Purpose |
| ------ | ------- |
| `medical_reports` | Exams, imaging, treatment records |
| `correspondence` | Letters, notices, board/employer communication |
| `decisions_and_orders` | Decisions, orders, rulings |
| `evidence` | Witness statements, photos, pay records |
| `personal_notes` | Your notes and drafts |
| `to_sort` | Unsorted intake |

Also use a root `AGENTS.md` as the case brief, and optional `core_references/`
for shared policy materials. Tutorials open a sample matter with this layout —
no credits and no AI.
