# Safe Appeals Neon Dark

Neon theme - Bold and modern

## Color Palette

- **Status Bar**: `#00FFF0`
- **Primary Accent**: `#00FFF0`
- **Secondary Accent**: `#FF00FF`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Neon)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Neon Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Neon)"

Or mix and match with any other icon theme!
