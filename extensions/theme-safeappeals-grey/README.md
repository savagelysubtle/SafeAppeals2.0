# Safe Appeals File Icon Theme (Grey Variant)

The grey folder variant of the Safe Appeals Navigator icon theme.

## Features

- **Grey Folder Icons**: Professional grey-toned folders for a neutral aesthetic
- **Root Folder Icons**: Darker grey for root/project folders with plus indicators
- **File Type Icons**: Same comprehensive file type support as the green theme

## Color Palette

The grey variant uses a sophisticated neutral color scheme:
- **Standard Folders**: Cool grey (#A0AEC0) for collapsed, light grey (#CBD5E0) for expanded
- **Root Folders**: Dark grey (#718096) with white plus indicators
- Maintains the same colorful file icons for easy file type identification

## When to Use

Choose the grey variant when you:
- Prefer a more neutral, minimalist aesthetic
- Want folders to be less prominent
- Like the file type colors but want subtler folders
- Are working in a distraction-free environment

## Technical Details

- All icons are SVG format for crisp rendering at any size
- Icons follow VSCode's icon theme specification
- Supports language-based icon selection
- Includes special icons for common configuration files

## Switching Themes

To switch between green and grey variants:
1. Press `Ctrl+Shift+P` (Command Palette)
2. Type "File Icon Theme"
3. Select "Preferences: File Icon Theme"
4. Choose between "Safe Appeals Icons" (green) or "Safe Appeals Icons (Grey)"
