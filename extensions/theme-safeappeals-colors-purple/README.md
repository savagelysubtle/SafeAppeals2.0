# Safe Appeals Purple Dark

Creative purple theme - Modern and sophisticated

## Color Palette

- **Status Bar**: `#9B7EDE`
- **Primary Accent**: `#9B7EDE`
- **Secondary Accent**: `#7B5EBE`

## Matching Icon Theme

This color theme is designed to match the **Safe Appeals Icons (Purple)** icon theme.

To get the full coordinated experience:
1. Select this color theme: `Ctrl+Shift+P` → "Color Theme" → "Safe Appeals Purple Dark"
2. Select matching icon theme: `Ctrl+Shift+P` → "File Icon Theme" → "Safe Appeals Icons (Purple)"

Or mix and match with any other icon theme!
