# File Organization System - Proof of Concept

## Overview

Create a Void extension that provides an intuitive file organization system using a 3-step wizard interface, leveraging Void's existing agent infrastructure for intelligent file classification.

## Architecture

### Core Components Location

### Phase 3: AI Integration with Void Agents

**7. Integrate with Void Agent System**

- Location: `src/vs/workbench/contrib/void/browser/fileOrganizer/aiClassifier.ts`
- Use existing `IVoidService` to communicate with agents
- Send file metadata to agent for classification
- Parse agent response for naming suggestions and tags
```typescript
export class AIFileClassifier {
  constructor(
    @IVoidService private voidService: IVoidService
  ) {}
  
  async classifyFile(file: FileMetadata): Promise<FileChange> {
    const prompt = this.buildClassificationPrompt(file);
    
    // Use Void's agent system
    const response = await this.voidService.sendMessage({
      role: 'user',
      content: prompt
    });
    
    return this.parseAgentResponse(response, file);
  }
  
  private buildClassificationPrompt(file: FileMetadata): string {
    return `Analyze this file and suggest:
1. Appropriate filename following convention: ProjectName_FileType_Version
2. Relevant tags (3-5 tags)
3. Project category

File name: ${file.name}
Extension: ${file.extension}
Size: ${file.size} bytes

Respond in JSON format.`;
  }
}
```


### Phase 4: File System Operations

**8. Implement File Operations**

- Use VSCode's `IFileService` for file system operations
- Implement safe rename/move operations
- Create backup/undo capability
- Handle errors gracefully (file locks, permissions, etc.)
```typescript
async applyChanges(changes: FileChange[]): Promise<Result[]> {
  const results: Result[] = [];
  
  for (const change of changes) {
    try {
      // Use VSCode file service
      await this.fileService.move(
        change.original.uri,
        this.buildNewURI(change)
      );
      
      // Store metadata/tags (could use file system extended attributes)
      await this.storeMetadata(change);
      
      results.push({ success: true, file: change.original.uri });
    } catch (error) {
      results.push({ success: false, file: change.original.uri, error });
    }
  }
  
  return results;
}
```

## POC Validation Criteria

### Success Metrics for POC

1. User can select 5-10 files from file system
2. Template selector displays and is clickable
3. Rule builder shows preview of naming pattern
4. Void agent returns intelligent suggestions
5. Review screen shows before/after comparison
6. Files are successfully renamed with one click
7. Total time from start to organized files: < 3 minutes

### Out of Scope for POC

- Advanced rule engine (use simple pattern matching)
- Undo/redo (can add later)
- Custom template creation (use pre-built only)
- File content analysis (metadata only)
- Batch processing of 100+ files (test with small sets)
- Cloud storage integration (local files only)
