# Cost Tracking and Model Economics

Comprehensive guide to AI model pricing, cost optimization, and usage monitoring across all supported providers.

## Cost Structure Overview

### Token-Based Pricing

Most AI providers use a token-based pricing model where costs are calculated per 1,000 tokens:

- **Input Tokens**: Text sent to the model (prompts, context, messages)
- **Output Tokens**: Text generated by the model (responses, completions)
- **Cached Tokens**: Pre-processed tokens stored for reuse (reduced cost)

### Cost Components

Each model defines pricing for different token types:

```typescript
cost: {
  input: number;        // Cost per 1K input tokens ($)
  output: number;       // Cost per 1K output tokens ($)
  cache_read?: number;  // Cost per 1K cached input tokens ($)
  cache_write?: number; // Cost to cache 1K input tokens ($)
}
```

### Cost Monitoring

#### Usage Tracking

```typescript
interface UsageMetrics {
  provider: string;
  model: string;
  tokens: {
    input: number;
    output: number;
    cached: number;
  };
  cost: number;
  timestamp: number;
  requestId: string;
}

class CostTracker {
  private usage: UsageMetrics[] = [];

  trackUsage(metrics: UsageMetrics) {
    this.usage.push(metrics);
    this.updateTotals(metrics);
  }

  getTotalCost(timeframe: 'day' | 'week' | 'month'): number {
    const since = this.getTimeframeStart(timeframe);
    return this.usage
      .filter(u => u.timestamp >= since)
      .reduce((total, u) => total + u.cost, 0);
  }

  getCostByModel(): Record<string, number> {
    return this.usage.reduce((acc, u) => {
      acc[u.model] = (acc[u.model] || 0) + u.cost;
      return acc;
    }, {} as Record<string, number>);
  }
}
```

#### Budget Alerts

```typescript
interface BudgetConfig {
  dailyLimit: number;
  monthlyLimit: number;
  alertThreshold: number;  // Percentage (0.8 = 80%)
}

class BudgetMonitor {
  checkBudget(currentSpend: number, config: BudgetConfig): BudgetAlert | null {
    const percentage = currentSpend / config.dailyLimit;

    if (percentage >= config.alertThreshold) {
      return {
        level: percentage >= 1 ? 'exceeded' : 'warning',
        currentSpend,
        limit: config.dailyLimit,
        percentage: Math.round(percentage * 100)
      };
    }

    return null;
  }
}
```

## Advanced Cost Optimization

### Model Switching

```typescript
class SmartModelSelector {
  selectModel(
    task: Task,
    budget: BudgetConstraints,
    quality: QualityRequirements
  ): SelectedModel {

    // Find models within budget
    const affordableModels = this.models.filter(m =>
      this.calculateEstimatedCost(m, task) <= budget.maxCost
    );

    // Rank by quality score
    const ranked = affordableModels.sort((a, b) =>
      b.qualityScore - a.qualityScore
    );

    return ranked[0] || this.fallbackModel;
  }

  calculateEstimatedCost(model: Model, task: Task): number {
    const estimatedTokens = this.estimateTokens(task);
    return (estimatedTokens.input * model.cost.input +
            estimatedTokens.output * model.cost.output) / 1000;
  }
}
```

### Quality-Cost Tradeoffs

#### Tiered Approach

```typescript
class TieredProcessing {
  async processWithFallback(
    task: Task,
    primaryModel: Model,
    fallbackModel: Model
  ): Promise<ProcessingResult> {

    try {
      // Try expensive model first
      const result = await this.processWithModel(task, primaryModel);

      if (this.meetsQualityThreshold(result)) {
        return result;
      }
    } catch (error) {
      console.warn('Primary model failed, using fallback');
    }

    // Fallback to cheaper model
    return this.processWithModel(task, fallbackModel);
  }
}
```

### Predictive Cost Analysis

```typescript
interface CostPrediction {
  estimatedCost: number;
  confidence: number;      // 0-1 scale
  breakdown: {
    inputTokens: number;
    outputTokens: number;
    reasoningTokens: number;
  };
}

class CostPredictor {
  predictCost(task: Task, model: Model): CostPrediction {
    const inputTokens = this.estimateInputTokens(task);
    const outputTokens = this.estimateOutputTokens(task, model);
    const reasoningTokens = this.estimateReasoningTokens(task, model);

    const totalTokens = inputTokens + outputTokens + reasoningTokens;
    const estimatedCost = this.calculateCost(totalTokens, model);

    return {
      estimatedCost,
      confidence: this.calculateConfidence(task, model),
      breakdown: { inputTokens, outputTokens, reasoningTokens }
    };
  }
}
```
